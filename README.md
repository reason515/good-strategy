# 这是什么

一页可滚动的网页，提炼理查德·鲁梅尔特《好战略，坏战略》与《好战略，坏战略2》的核心：坏战略的四种形态、诊断—指导方针—连贯性行动的内核、九个力量之源，以及攀岩者口中的「症结」。
